# Struck-Off Company Check — website

Live at **https://struckoffcompanies.com**. Screen vendors and customers against companies struck off by India's
Registrars of Companies (STK-7 notices, 2017–2026, 228,453 companies). Search a name or CIN, or upload a list;
files are read in the browser and never uploaded.

This repository only holds the published site. It is generated from the private project repository
(`struck-off-companies`) by `pipeline/build_website.py` and `pipeline/publish_site.sh`; don't edit it by hand.
